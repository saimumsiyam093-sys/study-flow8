# Study Spark

Create a modern, responsive Study Planner website for students.



Pages:

- Home

- Dashboard

- Subjects

- Homework

- Exams

- Notes

- About



Features:

- Add, edit, and delete subjects

- Add homework with due dates

- Add exam schedules with countdown

- Show today's tasks

- Mark tasks as completed

- Progress bar for completed work

- Calendar view

- Dark and light mode

- Search and filter tasks

- Save all data using Local Storage (no login required)



Design:

- Modern and colorful

- Mobile-friendly and responsive

- Smooth animations

- Clean navigation bar

- Beautiful cards with rounded corners

- Blue and green color theme

- Fast loading



Tech Stack:

- React

- TypeScript

- Tailwind CSS



The website should look professional, be easy to use, and work well on mobile, tablet, and desktop browsers.
